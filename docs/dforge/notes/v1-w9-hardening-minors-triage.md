## Fix before v1

Alternatively drop `shouldAdvanceTime` for this test and advance the fake clock explicitly. Test: run the file in a loop under load (for example `pnpm -C web vitest run src/components/change-dialog.a11y.test.tsx` repeated 200 times with a CPU hog running) and confirm no failure; the assertion text stays "Reverts automatically in 1 second unless confirmed."
