## Delta

**UI/UX depth:** touch — the connectors table, host choice and NPM banner keep long names inside their containers

- **UI-1** — In the "Connectors on <host>" table, the State badge ("running", "exited") stays on one line inside its cell at every viewport.
- **UI-2** — The connectors table is at least 40rem wide; where its wrapper is narrower (at 375 px always), the wrapper scrolls sideways (`overflow-x` auto or scroll) and its scroll width holds the whole table. The tunnel and container cells of the 64- and 62-character names are each at least 10 characters wide and stay inside the table, wrapping anywhere rather than one or two characters per line.
- **UI-3** — A 63-character host name in the Host radio group wraps inside the group instead of running past its right edge.
- **UI-4** — In the NPM "Admin interface exposed" banner, the "Open Nginx Proxy Manager on <host>" link and the "The NPM admin interface of … is exposed at https://…" description stay inside the banner, and the link is underlined at rest.
- **OP-1** — Proven at 375x812, 768x1024 and 1440x900, light and dark: no axe violation (WCAG 2.1 A and AA), no console error, no page-level horizontal scroll, and no API request without a fixture.
