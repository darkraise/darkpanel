## Assumptions (evidence)

- The `docker-proxy` holder of NPM's `[::]:443` names `-container-ip <addr> -container-port 443` on its command line under Docker 29.9.1 — unverified — Task 1 verifies it (spec, Riskiest assumption; Global Constraints, Early CI gate).
- Composite steps are rebuilt at apply and compared by state hash (`internal/core/lifecycle/composite_run.go:1124-1158`, `apply.go:333-337`); `Steps` reads no host state (`composite_deploy_expose.go:77-111`), so fixed ids make plan and apply equal (A4).
- `firewall.rules.apply` validates ids against `^[0-9A-HJKMNP-TV-Z]{26}$` (`internal/modules/firewall/actions_rules.go:35`) and refuses a rule with a comment (`:83-84`); the label becomes the comment (`:95`). DERP builds its ports step the same way (`internal/modules/derp/composite_deploy.go:65-82`).
- Today an add whose tuple a manual rule holds is refused by `manualChanges` (`internal/modules/firewall/plan.go:110-114`, `diff.go:84-95`), because the prediction replaces the manual tuple (`predict/edit.go:407,419-421`); `matchTuple` is unexported (`predict/edit.go:350-366`), so Task 2 exports a helper.
- `change.notes` makes `dockerLines` read the Docker store (`internal/modules/firewall/docker_diff.go:21-33`), so Task 2 adds its context lines through a separate field, not `notes`.
- The mutation's `finish` hook gets no post-change config (`internal/modules/firewall/handler.go:51`), so Task 2 passes it the config `check` already receives.
- New optional input fields keep a released schema compatible (`internal/core/schema/compare.go:37-43`, `TestReleasedSnapshotsCompatible` at `internal/modules/modules_test.go:106`); a removed version fails it, so v1 stays registered.
- No shipped action has a v2; the registry keys actions by name and version (`internal/core/registry.go:660-663`), the snapshot path is `<name>/v<version>.json` (`internal/core/schema/snapshot.go:73`), and the CLI takes the highest version (`internal/cli/names.go:61-64`).
- The guard compares only wild-source flows with the before-state (`internal/modules/firewall/guard/cells.go:61,297`) and reads no command line (`internal/platform/netstat/sockets.go:297` reads `comm` only); optional host capabilities are type-asserted (`guard/routes.go:8-16`).
- An out-of-sync host refuses every firewall change with a hard guard (`internal/modules/firewall/plan.go:137-147`), so A26 holds for the ports step once Task 2 leaves that path unchanged; Task 2's test pins it with `keepManual` set.
- The m3g spec runs only through Playwright with a Vite dev server per run (`web/playwright.config.ts`, `webServer`); no make target runs it.
