# M1 Web UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: the skill the **Execution:** line names — dr-superpowers:subagent-driven-development for `subagent`, dr-superpowers:executing-plans for `inline`. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the placeholder page with the walking-skeleton web UI: TOTP login behind a session guard, the hosts overview, registry-driven module pages with the host-information page, the audit log and API tokens, plus the folded-in web tooling fixes.

**Architecture:** A React 19 single-page app under `web/`, built by Vite and embedded in the Go binary. react-router in declarative mode drives the routes through a darkraise-ui router adapter built on `NavLink`; TanStack Query caches reads; one `fetch` wrapper talks to the controller API of spec section 12 with the session cookie and the CSRF header. Module pages come from `web/src/modules/registry.ts`, one line per module, each pointing at a lazily imported route bundle in `web/src/modules/<id>/`.

**Tech Stack:** TypeScript 6.0.3, React 19.3.1, darkraise-ui 6.9.6, react-router 8.4.0, @tanstack/react-query 5.104.3, lucide-react 1.58.0, Vite 8.3.4, Vitest 5.0.5 with jsdom and Testing Library, pnpm 11.17.0.

**API client (`api/client.ts`, Task 2):**
- `CSRF_HEADER = "X-CSRF-Token"`.
- `class ApiError extends Error` with readonly `status: number` (0 for a network failure), `code: string` (the problem's `code`, `"network"` when the controller cannot be reached, `"internal"` when the body has no code), `fields: FieldError[]`, `retryAfterSeconds: number | null` (from `Retry-After`); `message` is the problem's `detail`.
- `setCsrfToken(token: string | null): void` — the token every later `POST`, `PUT`, `PATCH` and `DELETE` sends in `X-CSRF-Token`.
- `setUnauthorizedHandler(handler: (() => void) | null): void` — called whenever a response carries code `auth.required`.
- `request<T>(method: string, path: string, body?: unknown): Promise<T>` — `credentials: "same-origin"`, `Accept` and `Content-Type: application/json`; resolves `undefined` on 204; rejects with `ApiError` on a non-2xx status or a network failure.
- `readAction<O>(name: string, version: number, input?: object, hostId?: string): Promise<O>` — POST `{input}` to the read route; resolves the response's `output`. Without `hostId` the route is `/api/v1/actions/<name>/v<version>/read`, with it `/api/v1/hosts/<hostId>/actions/<name>/v<version>/read`.
- `planAction(name: string, version: number, input: object, hostId?: string): Promise<Plan>` — POST `{input}` to the plan route.
- `applyPlan<O>(plan: Plan, confirmation?: string): Promise<Change<O>>` — POST `{planId}` (plus `confirmation` when given) to the apply route of `plan.action`, `plan.version` and `plan.hostId`.
- `readResource<O>(hostId: string, module: string, resource: string): Promise<O>` — GET `/api/v1/hosts/<hostId>/resources/<module>/<resource>`; the body is the output itself.
- `listHosts(): Promise<HostList>` (`core.host.list` v1), `listTokens(): Promise<TokenList>` (`core.token.list` v1), `getListenerState(): Promise<ListenerState>` (GET `/api/v1/controller/listeners`).
- `HOSTS_QUERY_KEY = ["hosts"] as const`, `TOKENS_QUERY_KEY = ["tokens"] as const` — the TanStack Query keys of those two lists.
- `errorMessage(err: unknown): string` — an `ApiError`'s message, else `"Something went wrong. Try again."`.
- `changeError(change: Change): string | null` — `null` for states `completed`, `confirmed` and `pending`; otherwise `change.error.message`, or `The change ended in state <state>.` when there is no error.

**Formatting (`lib/format.ts`, Task 3):** `formatBytes(bytes: number): string` (binary units B, KiB … PiB; no decimal for bytes or values of 100 and more, one decimal otherwise; `"—"` for a negative or non-finite value), `formatDuration(seconds: number): string` (`"3 d 4 h 5 min"`, `"4 h 5 min"`, `"5 min"`, `"42 s"`; `"—"` for a negative or non-finite value), `formatTime(iso: string | null): string` (`"—"` for null, the input unchanged when it does not parse, else `Intl.DateTimeFormat(undefined, { dateStyle: "medium", timeStyle: "short" })`).

```ts
function respond(status: number, body?: unknown, headers: Record<string, string> = {}): Response {
  const h = new Headers(headers)
  if (body !== undefined && !h.has("Content-Type")) {
    h.set("Content-Type", status >= 400 ? "application/problem+json" : "application/json")
  }
  return new Response(body === undefined ? null : JSON.stringify(body), { status, headers: h })
}

function stub(res: Response | (() => Promise<Response>)) {
  const fetchMock = vi.fn<typeof fetch>()
  if (res instanceof Response) fetchMock.mockResolvedValue(res)
  else fetchMock.mockImplementation(res)
  vi.stubGlobal("fetch", fetchMock)

function sent(fetchMock: ReturnType<typeof stub>) {
  const call = fetchMock.mock.calls[0]
  if (call === undefined) throw new Error("fetch was not called")
  const [url, init] = call
  return {
    url: String(url),
    method: init?.method,
    credentials: init?.credentials,
    headers: new Headers(init?.headers),
    body: typeof init?.body === "string" ? (JSON.parse(init.body) as unknown) : undefined,
```

```ts
import type { Change, FieldError, HostList, ListenerState, Plan, Problem, TokenList } from "./types"

export const CSRF_HEADER = "X-CSRF-Token"

export const HOSTS_QUERY_KEY = ["hosts"] as const
export const TOKENS_QUERY_KEY = ["tokens"] as const

const UNSAFE_METHODS = new Set(["POST", "PUT", "PATCH", "DELETE"])
const SUCCESSFUL_STATES = new Set(["completed", "confirmed", "pending"])

export class ApiError extends Error {
  readonly status: number
  readonly code: string
  readonly fields: FieldError[]
  readonly retryAfterSeconds: number | null

  constructor(status: number, code: string, message: string, fields: FieldError[] = [], retryAfterSeconds: number | null = null) {
    super(message)
    this.name = "ApiError"
    this.status = status
    this.code = code
    this.fields = fields
    this.retryAfterSeconds = retryAfterSeconds
  }
}

let csrfToken: string | null = null
let unauthorizedHandler: (() => void) | null = null

export function setCsrfToken(token: string | null): void {
  csrfToken = token
}

export function setUnauthorizedHandler(handler: (() => void) | null): void {
  unauthorizedHandler = handler
}

export async function request<T>(method: string, path: string, body?: unknown): Promise<T> {
  const headers: Record<string, string> = { Accept: "application/json", "Content-Type": "application/json" }
  if (UNSAFE_METHODS.has(method) && csrfToken !== null) headers[CSRF_HEADER] = csrfToken
  let res: Response
  try {
    res = await fetch(path, {
      method,
      headers,
      credentials: "same-origin",
      body: body === undefined ? undefined : JSON.stringify(body),
    })
  } catch {
    throw new ApiError(0, "network", "The controller cannot be reached. Check that it is running.")
  }
  if (!res.ok) {
    const err = await problemFrom(res)
    if (err.code === "auth.required") unauthorizedHandler?.()
    throw err
  }
  if (res.status === 204) return undefined as T
  return (await res.json()) as T
}

async function problemFrom(res: Response): Promise<ApiError> {
  let problem: Partial<Problem> = {}
  if ((res.headers.get("Content-Type") ?? "").includes("json")) {
    try {
      problem = (await res.json()) as Partial<Problem>
    } catch {
      problem = {}
    }
  }
  const retryAfter = Number.parseInt(res.headers.get("Retry-After") ?? "", 10)
  return new ApiError(
    res.status,
    problem.code ?? "internal",
    problem.detail || res.statusText || "The request failed.",
    problem.errors ?? [],
    Number.isNaN(retryAfter) ? null : retryAfter,
  )
}

function actionPath(name: string, version: number, op: "plan" | "apply" | "read", hostId?: string): string {
  const tail = `/actions/${encodeURIComponent(name)}/v${version}/${op}`
  return hostId === undefined ? `/api/v1${tail}` : `/api/v1/hosts/${encodeURIComponent(hostId)}${tail}`
}

export async function readAction<O>(name: string, version: number, input: object = {}, hostId?: string): Promise<O> {
  const res = await request<{ output: O }>("POST", actionPath(name, version, "read", hostId), { input })
  return res.output
}

export function planAction(name: string, version: number, input: object, hostId?: string): Promise<Plan> {
  return request<Plan>("POST", actionPath(name, version, "plan", hostId), { input })
}

export function applyPlan<O>(plan: Plan, confirmation?: string): Promise<Change<O>> {
  const body: { planId: string; confirmation?: string } = { planId: plan.planId }
  if (confirmation !== undefined) body.confirmation = confirmation
  return request<Change<O>>("POST", actionPath(plan.action, plan.version, "apply", plan.hostId ?? undefined), body)
}

export function readResource<O>(hostId: string, module: string, resource: string): Promise<O> {
  const path = [hostId, "resources", module, resource].map(encodeURIComponent).join("/")
  return request<O>("GET", `/api/v1/hosts/${path}`)
}

export function listHosts(): Promise<HostList> {
  return readAction<HostList>("core.host.list", 1)
}

export function listTokens(): Promise<TokenList> {
  return readAction<TokenList>("core.token.list", 1)
}

export function getListenerState(): Promise<ListenerState> {
  return request<ListenerState>("GET", "/api/v1/controller/listeners")
}

export function errorMessage(err: unknown): string {
  return err instanceof ApiError ? err.message : "Something went wrong. Try again."
}

export function changeError(change: Change): string | null {
  if (SUCCESSFUL_STATES.has(change.state)) return null
  return change.error?.message ?? `The change ended in state ${change.state}.`
}
```

```ts
const BYTE_UNITS = ["B", "KiB", "MiB", "GiB", "TiB", "PiB"]

const timeFormat = new Intl.DateTimeFormat(undefined, { dateStyle: "medium", timeStyle: "short" })

export function formatBytes(bytes: number): string {
  if (!Number.isFinite(bytes) || bytes < 0) return "—"
  let value = bytes
  let unit = 0
  while (value >= 1024 && unit < BYTE_UNITS.length - 1) {
    value /= 1024
    unit++
  }
  const digits = unit === 0 || value >= 100 ? 0 : 1
  return `${value.toFixed(digits)} ${BYTE_UNITS[unit]}`
}

export function formatDuration(totalSeconds: number): string {
  if (!Number.isFinite(totalSeconds) || totalSeconds < 0) return "—"
  const seconds = Math.floor(totalSeconds)
  const days = Math.floor(seconds / 86400)
  const hours = Math.floor((seconds % 86400) / 3600)
  const minutes = Math.floor((seconds % 3600) / 60)
  if (days > 0) return `${days} d ${hours} h ${minutes} min`
  if (hours > 0) return `${hours} h ${minutes} min`
  if (minutes > 0) return `${minutes} min`
  return `${seconds} s`
}

export function formatTime(iso: string | null): string {
  if (iso === null) return "—"
  const date = new Date(iso)
  return Number.isNaN(date.getTime()) ? iso : timeFormat.format(date)
}
```

```tsx
import type { AnchorHTMLAttributes, Ref } from "react"
import { NavLink, useLocation, useNavigate } from "react-router"
import { useQueryClient } from "@tanstack/react-query"
import type { RouterAdapter, RouterLinkProps } from "darkraise-ui/router"

// darkraise-ui passes more than RouterLinkProps at run time (a tooltip
// trigger's handlers, ids and ref through asChild), so everything but the
// adapter's own props goes on to the anchor.
type AdapterLinkProps = RouterLinkProps & AnchorHTMLAttributes<HTMLAnchorElement> & { ref?: Ref<HTMLAnchorElement> }

// NavLink sets aria-current="page" on the active link, which darkraise-ui
// requires of every router adapter.
function AdapterLink({ to, className, activeClassName, activeExact, children, ...rest }: AdapterLinkProps) {
  return (
    <NavLink
      {...rest}
      to={to}
      end={activeExact}
      className={({ isActive }) => [className, isActive ? activeClassName : undefined].filter(Boolean).join(" ") || undefined}
    >
      {children}
    </NavLink>
  )
}

function useAdapterNavigate(): (to: string) => void {
  const navigate = useNavigate()
  return (to) => {
    void navigate(to)
  }
}

function useAdapterPathname(): string {
  return useLocation().pathname
}

function useAdapterBack(): () => void {
  const navigate = useNavigate()
  return () => {
    void navigate(-1)
  }
}

function useAdapterInvalidate(): () => void {
  const client = useQueryClient()
  return () => {
    void client.invalidateQueries()
  }
}

export const routerAdapter: RouterAdapter = {
  Link: AdapterLink,
  useNavigate: useAdapterNavigate,
  usePathname: useAdapterPathname,
  useBack: useAdapterBack,
  useInvalidate: useAdapterInvalidate,
}
```

```js
// Restores the persisted theme before React mounts, so the first paint
// matches it. Loaded with a plain <script src> because the CSP allows no
// inline script. With nothing stored it falls back to dark, the default in
// src/theme.config.ts.
;(function () {
  const mode = localStorage.getItem("mode") || "dark"
  const resolved =
    mode === "system"
      ? window.matchMedia("(prefers-color-scheme: dark)").matches
        ? "dark"
        : "light"
      : mode
  document.documentElement.setAttribute("data-mode", resolved)

  // Restore every attribute-driven theme axis. The attribute-name to
  // localStorage-key map mirrors darkraise-ui's ThemeProvider — note
  // "theme-bg-style" / "theme-bg-intensity" are NOT just kebab-cased
  // "background-*" keys.
  const AXIS_LS_KEYS = {
    preset: "theme-preset",
    "background-style": "theme-bg-style",
    "background-intensity": "theme-bg-intensity",
    "gradient-pattern": "theme-gradient-pattern",
    density: "theme-density",
    elevation: "theme-elevation",
    "button-elevation": "theme-button-elevation",
    "surface-intensity": "theme-surface-intensity",
    radius: "theme-radius",
    "control-depth": "theme-control-depth",
    "shell-style": "theme-shell-style",
    "sidebar-active-bar": "theme-sidebar-active-bar",
    "font-size": "theme-font-size",
    "outer-glow": "theme-outer-glow",
    "inner-glow": "theme-inner-glow",
  }
  // Presets that reinterpret an axis neutralise it rather than merely hiding
  // its control, so restoring a stored value here would flash the wrong
  // surface treatment before hydration corrects it. Mirrors
  // NEUTRALISED_WHEN_HIDDEN + hiddenCommonAxes in the library.
  const NEUTRALISED_BY_PRESET = {
    glass: ["surface-intensity"],
    scifi: ["surface-intensity"],
  }
  const activePreset = localStorage.getItem("theme-preset") || ""
  const neutralised = NEUTRALISED_BY_PRESET[activePreset] || []
  Object.keys(AXIS_LS_KEYS).forEach(function (axis) {
    if (neutralised.indexOf(axis) !== -1) return
    const v = localStorage.getItem(AXIS_LS_KEYS[axis])
    if (v) document.documentElement.setAttribute("data-" + axis, v)
  })
})()
```

```tsx
import { createContext, useCallback, useContext, useEffect, useMemo, useState, type ReactNode } from "react"
import { Navigate, useLocation } from "react-router"
import { useQueryClient } from "@tanstack/react-query"
import { Spinner } from "darkraise-ui/components/spinner"
import { request, setCsrfToken, setUnauthorizedHandler } from "@/api/client"
import type { Session } from "@/api/types"

interface SessionState {
  status: "loading" | "ready"
  session: Session | null
}

interface SessionContextValue extends SessionState {
  setSession: (session: Session | null) => void
}

const SessionContext = createContext<SessionContextValue | null>(null)

export function SessionProvider({ children }: { children: ReactNode }) {
  const client = useQueryClient()
  const [state, setState] = useState<SessionState>({ status: "loading", session: null })

  const setSession = useCallback(
    (session: Session | null) => {
      setCsrfToken(session?.csrfToken ?? null)
      if (session === null) client.clear()
      setState({ status: "ready", session })
    },
    [client],
  )

  useEffect(() => {
    let active = true
    setUnauthorizedHandler(() => {
      if (active) setSession(null)
    })
    request<Session>("GET", "/api/v1/auth/session").then(
      (session) => {
        if (active) setSession(session)
      },
      () => {
        if (active) setSession(null)
      },
    )
    return () => {
      active = false
      setUnauthorizedHandler(null)
    }
  }, [setSession])

  const value = useMemo(() => ({ ...state, setSession }), [state, setSession])
  return <SessionContext value={value}>{children}</SessionContext>
}

export function useSession(): SessionContextValue {
  const value = useContext(SessionContext)
  if (value === null) throw new Error("useSession must be used inside SessionProvider")
  return value
}

// safeNext keeps a post-login redirect inside the app. Browsers drop tabs
// and newlines from URLs and read a backslash as a slash, so "/\t/host" and
// "/\host" name another origin; those characters are refused outright, and
// what is left must resolve to this origin.
export function safeNext(next: string | null): string {
  // eslint-disable-next-line no-control-regex
  if (next === null || !next.startsWith("/") || /[\u0000-\u001f\u007f\\]/.test(next)) return "/"
  let url: URL
  try {
    url = new URL(next, window.location.origin)
  } catch {
    return "/"
  }
  if (url.origin !== window.location.origin || url.pathname === "/login" || url.pathname.startsWith("/login/")) return "/"
  return url.pathname + url.search + url.hash
}

export function SessionSpinner() {
  return (
    <div className="flex justify-center py-16">
      <Spinner aria-label="Loading" />
    </div>
  )
}

export function RequireSession({ children }: { children: ReactNode }) {
  const { status, session } = useSession()
  const location = useLocation()
  if (status === "loading") return <SessionSpinner />
  if (session === null) {
    const next = location.pathname + location.search
    return <Navigate to={next === "/" ? "/login" : `/login?next=${encodeURIComponent(next)}`} replace />
  }
  return <>{children}</>
}
```

```tsx
import { ApiError, request } from "@/api/client"
import type { Session } from "@/api/types"
import { SessionSpinner, safeNext, useSession } from "@/session/session"

const GENERIC_ERROR = "Login failed. Check the username, password and code, then try again."

// The login page shows one generic error, so it reveals nothing about which
// of the three fields was wrong (spec section 17).
function loginError(err: unknown): string {
  if (err instanceof ApiError && err.code === "auth.rate_limited") {
    return err.retryAfterSeconds === null
      ? "Too many attempts. Try again later."
      : `Too many attempts. Try again in ${err.retryAfterSeconds} seconds.`
  }
  if (err instanceof ApiError && err.code === "network") return err.message
  return GENERIC_ERROR
}

export function LoginPage() {
  const { status, session, setSession } = useSession()
  const [params] = useSearchParams()
  const [error, setError] = useState<string | null>(null)
  const [busy, setBusy] = useState(false)
  const next = safeNext(params.get("next"))

  if (status === "loading") return <SessionSpinner />
  if (session !== null) return <Navigate to={next} replace />

  async function submit(event: FormEvent<HTMLFormElement>) {
    event.preventDefault()
    const form = new FormData(event.currentTarget)
    setBusy(true)
    setError(null)
    try {
      setSession(
        await request<Session>("POST", "/api/v1/auth/login", {
          username: String(form.get("username") ?? ""),
          password: String(form.get("password") ?? ""),
          code: String(form.get("code") ?? ""),
        }),
      )
    } catch (err) {
      setError(loginError(err))
      setBusy(false)
    }
  }

  return (
    <main className="flex min-h-screen items-center justify-center p-4">
      <Card className="w-full max-w-sm">

          <CardTitle>
            <h1 className="text-xl font-medium">Darkpanel</h1>
          </CardTitle>
        </CardHeader>

              <Input id="login-username" name="username" autoComplete="username" required autoFocus />
            </div>
            <div className="flex flex-col gap-2">
              <Label htmlFor="login-password">Password</Label>
              <Input id="login-password" name="password" type="password" autoComplete="current-password" required />
            </div>
            <div className="flex flex-col gap-2">
              <Label htmlFor="login-code">Authentication code</Label>

                id="login-code"
                name="code"
                inputMode="numeric"

              />
            </div>

                <AlertDescription>{error}</AlertDescription>

            <Button type="submit" loading={busy}>
              Log in
            </Button>
          </form>
        </CardContent>
      </Card>

  )
```

```ts
import { lazy } from "react"
import { Info } from "lucide-react"
import type { Host } from "@/api/types"
import type { ModuleEntry } from "./types"

// One line per module (R14). Adding a module adds its line here and its
// folder modules/<id>/; no other module's files change.
export const moduleRegistry: ModuleEntry[] = [
  { id: "hostinfo", label: "Host information", icon: Info, routes: lazy(() => import("./hostinfo/routes")) },
]

export type ModuleView =
  | { kind: "pages"; entry: ModuleEntry }
  | { kind: "unavailable"; entry: ModuleEntry; reason: string }
  | { kind: "not-enabled" }

// enabledModules lists, in registry order, the entries the host has enabled.
export function enabledModules(entries: ModuleEntry[], host: Host): ModuleEntry[] {
  return entries.filter((entry) => host.modules.some((state) => state.id === entry.id && state.enabled))
}

// moduleView decides what a module's tab shows: its pages, or the reason an
// enabled module is unavailable (R9), or that it is not enabled.
export function moduleView(entries: ModuleEntry[], host: Host, moduleId: string): ModuleView {
  const entry = enabledModules(entries, host).find((e) => e.id === moduleId)
  const state = host.modules.find((s) => s.id === moduleId)
  if (entry === undefined || state === undefined) return { kind: "not-enabled" }
  if (!state.available) return { kind: "unavailable", entry, reason: state.reason ?? "The module is unavailable on this host." }
  return { kind: "pages", entry }
}
```

```tsx
import { useState, type FormEvent } from "react"
import { useQuery, useQueryClient } from "@tanstack/react-query"
import { Alert, AlertDescription } from "darkraise-ui/components/alert"
import { Button } from "darkraise-ui/components/button"
import { Dialog, DialogContent, DialogDescription, DialogFooter, DialogHeader, DialogTitle } from "darkraise-ui/components/dialog"
import { Input } from "darkraise-ui/components/input"
import { Label } from "darkraise-ui/components/label"
import { Spinner } from "darkraise-ui/components/spinner"
import { TOKENS_QUERY_KEY, applyPlan, changeError, errorMessage, planAction } from "@/api/client"
import type { TokenInfo } from "@/api/types"

function RevokeForm({ token, onDone }: { token: TokenInfo; onDone: () => void }) {
  const client = useQueryClient()
  // A fresh plan per opening: gcTime 0 drops it when the dialog closes.
  const plan = useQuery({
    queryKey: ["plan", "core.token.revoke", token.id],
    queryFn: () => planAction("core.token.revoke", 1, { id: token.id }),
    staleTime: Infinity,
    gcTime: 0,
  })
  const [typed, setTyped] = useState("")
  const [busy, setBusy] = useState(false)
  const [error, setError] = useState<string | null>(null)

  async function revoke(event: FormEvent<HTMLFormElement>) {
    event.preventDefault()
    if (plan.data === undefined) return
    setBusy(true)
    setError(null)
    try {
      const change = await applyPlan(plan.data, plan.data.confirmation === null ? undefined : typed)
      const failure = changeError(change)
      if (failure !== null) {
        setError(failure)
        return
      }
      void client.invalidateQueries({ queryKey: TOKENS_QUERY_KEY })
      onDone()
    } catch (err) {
      setError(errorMessage(err))
    } finally {
      setBusy(false)
    }
  }

  return (
    <>
      <DialogHeader>
        <DialogTitle>{`Revoke token ${token.name}`}</DialogTitle>
        <DialogDescription>Scripts that use this token stop working at once. This cannot be undone.</DialogDescription>
      </DialogHeader>
      {plan.isPending ? (
        <Spinner aria-label="Preparing the revocation" />
      ) : plan.isError ? (
        <Alert variant="destructive" role="alert">
          <AlertDescription>{errorMessage(plan.error)}</AlertDescription>
        </Alert>
      ) : (
        <form className="flex flex-col gap-4" onSubmit={(event) => void revoke(event)}>
          {plan.data.confirmation !== null && (
            <div className="flex flex-col gap-2">
              <Label htmlFor="revoke-confirmation">
                Type <code className="font-mono">{plan.data.confirmation}</code> to confirm
              </Label>
              <Input
                id="revoke-confirmation"
                className="font-mono"
                autoComplete="off"
                value={typed}
                onChange={(event) => setTyped(event.target.value)}
              />
            </div>
          )}
          {error !== null && (
            <Alert variant="destructive" role="alert">
              <AlertDescription>{error}</AlertDescription>
            </Alert>
          )}
          <DialogFooter>
            <Button
              type="submit"
              variant="destructive"
              loading={busy}
              disabled={plan.data.confirmation !== null && typed !== plan.data.confirmation}
            >
              Revoke
            </Button>
          </DialogFooter>
        </form>
      )}
    </>
  )
}

export function RevokeTokenDialog({ token, onClose }: { token: TokenInfo | null; onClose: () => void }) {
  return (
    <Dialog
      open={token !== null}
      onOpenChange={(open) => {
        if (!open) onClose()
      }}
    >
      <DialogContent>{token !== null && <RevokeForm key={token.id} token={token} onDone={onClose} />}</DialogContent>
    </Dialog>
  )
}
```

```tsx
function ListenerNotice() {
  const listeners = useQuery({ queryKey: ["listeners"], queryFn: getListenerState, refetchInterval: 30_000 })
  if (listeners.isPending) return null
  if (listeners.isError) {
    return (
      <p role="status" className="px-3 py-2 text-xs text-destructive">
        {`Listener state unavailable: ${errorMessage(listeners.error)}`}
      </p>
    )

      {listeners.data.message}
    </p>
  )
}

export function Shell() {
  const { session, setSession } = useSession()
  const [logoutError, setLogoutError] = useState<string | null>(null)

  // Only a logout the server confirmed ends the local session: the session
  // cookie is HttpOnly, so after a failure the browser would still be logged
  // in on reload. An auth.required answer ends it through the client's
  // unauthorized handler. Either way the guard then sends the page to the
  // login page.
  async function logout() {
    setLogoutError(null)
    try {
      await request<void>("POST", "/api/v1/auth/logout")
      setSession(null)
    } catch (err) {
      setLogoutError(`Logout failed: ${errorMessage(err)}`)
    }
  }

  return (

      nav={NAV}
      showThemeSwitcher
      showLayoutSwitcher={false}
      notificationSlot={null}
      user={session === null ? undefined : { name: session.user.username, email: session.user.role }}
```
